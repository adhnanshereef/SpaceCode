# SpaceCode 🚀

A beautiful, modern online code compiler with professional dark theme, glass morphism effects, and support for multiple programming languages. Built as a pure vanilla web application - no server required!

> **Developed by [Adhnan](https://www.adhnan.tech/)** - A modern, professional online IDE solution

## Features ✨

- **Beautiful UI**: Professional dark theme with gradient colors, blur effects, and glass morphism
- **Multi-language Support**: Python, C++, Java, and HTML rendering
- **Modern Code Editor**: 
  - Line numbers
  - Syntax highlighting
  - Auto-closing brackets and quotes
  - Tab indentation support
  - Code formatting
- **Interactive Output Terminal**: Real-time output display with typewriter effect
- **HTML Preview**: Live rendering of HTML code with CSS and JavaScript
- **Professional Features**:
  - Fullscreen editor mode
  - Output download functionality
  - Toast notifications
  - Loading animations
  - Responsive design

## Technologies Used 🛠️

- **Frontend**: HTML5, CSS3, Vanilla JavaScript (ES6+)
- **Styling**: Glass morphism, CSS gradients, backdrop-filter
- **Icons**: Font Awesome (CDN)
- **Fonts**: Google Fonts (Inter & Fira Code)
- **Syntax Highlighting**: Prism.js (CDN)
- **Deployment**: Static hosting (Netlify, Vercel, GitHub Pages compatible)

## Getting Started 🚀

### Prerequisites
- Modern web browser (Chrome, Firefox, Safari, Edge)
- No server installation required!

### Running the Application

Simply open `index.html` in your web browser by:
- Double-clicking the `index.html` file
- Right-click → "Open with" → Your preferred browser
- Drag and drop the file into your browser window

## Usage 📖

1. **Select Language**: Choose from Python, C++, Java, or HTML from the dropdown
2. **Write Code**: Use the code editor with syntax highlighting and line numbers
3. **Run Code**: Click the "Run" button to execute your code
4. **View Output**: See results in the output panel or HTML preview (for HTML)
5. **Additional Features**:
   - Format your code with the format button
   - Toggle fullscreen mode for focused coding
   - Clear editor or output as needed
   - Download output results
